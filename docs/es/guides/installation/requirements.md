# Requisitos del sistema

## Resumen

Neko-Void OS ofrece un sistema operativo ligero basado en Void Linux optimizado para bajo consumo de recursos y alto rendimiento en diferentes configuraciones de hardware.

## Tabla de requisitos

| Categoría | Requisitos mínimos | Requisitos recomendados |
|---|---|---|
| **Entornos XFCE, MATE e IceWM** | 2 GB de RAM | 4 GB de RAM |
| **Otros entornos de escritorio** | 4 GB de RAM | 4 GB de RAM o más |
| **Procesador** | Intel Celeron o Pentium de 1 núcleo (1.10 GHz, 64 bits) o equivalente | Intel Celeron / Pentium 2ª gen o superior (2 núcleos, 64 bits) |
| **Almacenamiento** | 64 GB de espacio disponible | 64 GB o más (SSD recomendado) |
| **Memoria gráfica** | GPU integrada o dedicada con 16 MB de VRAM | iGPU o GPU dedicada con 512 MB de VRAM o más |

## Notas adicionales

- Se requiere una arquitectura de procesador de **64 bits** (`x86_64`).
- Se recomienda disponer de una conexión a Internet para recibir actualizaciones durante o tras la instalación.
