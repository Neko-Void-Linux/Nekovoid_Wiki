# Guía de instalación

Neko-Void OS está diseñado para instalarse de forma rápida y sencilla mediante un medio de instalación USB y un instalador gráfico intuitivo.

Para realizar una instalación completa, sigue las secciones en orden:

1. **[Requisitos del sistema](./requirements)**: Verifica que tu hardware cumpla con los requisitos mínimos o recomendados.
2. **[Crear medio de instalación](./installation-media)**: Descarga la ISO y crea una memoria USB booteable con Ventoy.
3. **[Arranque en modo Live](./booting)**: Inicia tu equipo desde la memoria USB en la sesión Live.
4. **[Instalar Neko Void](./installing)**: Ejecuta el instalador paso a paso para configurar particiones, usuarios y arranque.
