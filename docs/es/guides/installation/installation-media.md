# Creando un medio de instalación

La forma más facil de instalar Neko Void es creando un medio de instalación con una memoria USB

En este caso podremos usar Ventoy como opción recomendada para la instalación


# En Windows, MacOS o Linux

Descarga [Ventoy](https://www.ventoy.net/en/download.html), Descomprimelo y abrelo.

[Imagen referencial de Ventoy2disk aquí]


Selecciona tu memoria USB y presiona el botón install. Cuando ya lo hayas echo simplemente arrastra la imagen ISO de Neko Void a tu memoria.
