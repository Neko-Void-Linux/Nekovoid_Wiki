# Acerca de Nosotros (^._.^)ﾉ

Nuestro enfoque principal es ofrecer la velocidad de un sistema base minimalista junto con una experiencia de escritorio lista para usar. Facilitamos el uso de un entorno libre de systemd mediante instaladores gráficos y herramientas nativas de post-instalación. El sistema está optimizado para diversos flujos de trabajo diarios, cubriendo (a) juegos [+..••], (b) diseño, (c) producción musical ♪, (d) edición de video [|>], y (e) tareas de oficina.

## Características del Ecosistema (b^_^)b

Trabajamos para entregar un sistema operativo altamente funcional nada más sacarlo de la caja. Neko Void incluye soporte completo para Vulkan con controladores Intel y AMD preconfigurados, integración nativa de PipeWire para cargas de trabajo multimedia y herramientas listas para usar como iruka-xbps, Neko-Kernel-Manager, Vouru, Falcond y btop. Admitimos arquitecturas con sistemas UEFI y BIOS Legacy para garantizar la máxima compatibilidad de hardware.

## Proyectos y Colaboración ヽ(´▽`)/

Dentro de esta organización, gestionamos el entorno de desarrollo y fomentamos la colaboración en código abierto. Desarrollamos y mantenemos el núcleo de la distribución, herramientas lanzadoras asociadas y repositorios de software. Buscamos eliminar las barreras de entrada manteniendo la eficiencia que caracteriza al sistema base.
