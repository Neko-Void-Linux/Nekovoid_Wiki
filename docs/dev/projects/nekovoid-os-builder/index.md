# Neko-Void OS Builder

This guide explains how to build the Neko Void Live ISO, which includes non-free support (Steam, gaming, proprietary drivers) out of the box.

## Setup

First, clone the repository and initialize the submodules:

```bash
git clone https://codeberg.org/javiercplus/Neko-Void.git
cd Neko-Void
git submodule update --init --recursive
```
