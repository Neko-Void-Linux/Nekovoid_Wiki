# Contributing

> The Neko-Void wiki is free documentation. It improves because people contribute to it.

This section explains how to add, fix, and maintain wiki pages.

## Start here

- **[How to contribute](./how-to-contribute)** — the workflow: fork, branch, write, pull request. If you have never contributed, read this first.
- **[Style guide](./style-guide)** — how to write a page: structure, tone, formatting. Every page in the wiki follows it.

## Why a style guide?

A wiki without rules becomes inconsistent: each page looks different, the tone drifts, and readers stop trusting it. The style guide is short, and it is the reason the Arch Wiki is a reference — not its size, but its consistency.

Read it once. Apply it always.

## Who can contribute?

Anyone. You do not need to be a Neko-Void developer, a Trinity team member, or a Linux expert. The most useful contributions are often the simplest: a corrected command, a clarified sentence, a translation.

## Where help is needed

- Translating English pages to Spanish (and vice versa).
- Writing the troubleshooting entries from real issues users hit.
- Documenting hardware support (NVIDIA, Wi-Fi, laptops).
- Improving the Getting Started flow for new users.

Open an issue if you want to pick up one of these and need a starting point.
