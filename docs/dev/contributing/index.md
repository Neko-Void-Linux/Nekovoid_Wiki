# Contributing

> The Neko-Void wiki is free documentation. It grows because people contribute to it.

This section explains how to add, fix, and maintain wiki pages.

## Start here

- **[How to contribute](./how-to-contribute)** — the workflow: fork, branch, write, pull request. Read this first if you have never contributed.
- **[Style guide](./style-guide)** — how to write a page: structure, tone, formatting. Every page in the wiki follows it.

## Why a style guide?

A wiki without rules drifts: each page looks different, the tone shifts, readers stop trusting it. The Arch Wiki is a reference not because of its size but because of its consistency. Our style guide is short and keeps the wiki on the same line.

## Who can contribute?

Anyone. You do not need to be a Neko-Void developer or a Linux expert. The most useful contributions are often the simplest: a corrected command, a clarified sentence, a translation.

## Where help is needed

- Translating English pages to Spanish, and vice versa.
- Writing troubleshooting entries from real issues users hit.
- Documenting hardware support (NVIDIA, Wi-Fi, laptops).
- Improving the Getting Started flow for new users.

Open an issue if you want to pick up one of these and need a starting point.
