# System Requirements

## Overview

Neko-Void OS provides a lightweight operating system built on top of Void Linux, optimized for low resource consumption and solid performance across diverse hardware.

## Requirements Table

| Category | Minimum Requirements | Recommended Requirements |
|---|---|---|
| **XFCE, MATE & IceWM Editions** | 2 GB RAM | 4 GB RAM |
| **Other Desktop Environments** | 4 GB RAM | 4 GB RAM or more |
| **Processor** | Intel Celeron or Pentium 1-core (1.10 GHz, 64-bit) or equivalent | Intel Celeron / Pentium 2nd gen or higher (2 cores, 64-bit) |
| **Storage** | 64 GB available disk space | 64 GB or more (SSD recommended) |
| **Graphics** | Integrated or dedicated GPU with 16 MB VRAM | iGPU or dedicated GPU with 512 MB VRAM or more |

## Additional Notes

- A **64-bit** (`x86_64`) architecture is required.
- An active internet connection is recommended during or after installation to fetch package updates.
