# Booting into Live Mode

## Overview

Live mode allows you to test Neko-Void OS directly from the USB drive without modifying your storage drives, and provides access to the graphical installer.

## Steps

1. **Insert the USB drive**: Plug your prepared USB drive into your computer.
2. **Restart your machine**: Reboot your PC.
3. **Open the Boot Menu**: During startup, repeatedly press your motherboard's Boot Menu key (commonly `F12`, `F11`, `F8`, `F10`, or `Esc` depending on your BIOS/UEFI manufacturer).
4. **Select the USB drive**: In the boot device list, select your USB drive.
5. **Boot Neko Void**: From the bootloader menu (GRUB or Ventoy), select the first option to boot Neko Void in Live mode and press `Enter`.

## Live Session Credentials

If prompted for login credentials in the Live session or terminal, use the default values:

- **Username:** `anon`
- **Password:** `voidlinux`
