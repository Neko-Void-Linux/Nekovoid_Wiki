# Documentation & Guides

Welcome to the Neko Void documentation portal. Neko Void is an open source ecosystem designed to deliver a lightweight, high-performance, and fully configured Void Linux desktop experience.

Here you will find practical installation guides, core architecture concepts, configuration instructions, and contributor resources.

## Where to Start?

If you are new to Neko Void, we recommend following these steps:

1. **[Installation Guide](./installation/)**: Check hardware requirements, create a bootable USB, and install Neko Void using the Kasha Installer.
2. **[System Concepts](../docs/concepts/runit)**: Understand core components such as the [runit init system](../docs/concepts/runit), [musl libc](../docs/concepts/musl), and display servers ([Wayland](../docs/concepts/wayland) / [Xorg](../docs/concepts/xorg)).
3. **[Configuration](../docs/configuration/)**: Customize desktop environments, global settings, and system defaults.
4. **[Troubleshooting](./troubleshooting/common-issues)**: Diagnose and resolve frequent setup and hardware questions.
