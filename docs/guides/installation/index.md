# Installation Guide

Neko-Void OS is designed to be installed quickly and easily using a bootable USB drive and an intuitive graphical installer.

Follow these steps in order to complete your installation:

1. **[System Requirements](./requirements)**: Verify that your hardware meets the minimum or recommended requirements.
2. **[Create Installation Media](./installation-media)**: Download the ISO and create a bootable USB drive with Ventoy.
3. **[Booting into Live Mode](./booting)**: Start your computer from the USB drive into the Live session.
4. **[Installing Neko Void](./installing)**: Follow the installer step by step to configure partitions, users, and the bootloader.
